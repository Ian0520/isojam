# IsoJam Project Scope

## Goal

Build a web application that helps musicians create practice tracks from uploaded songs using audio source separation.

## Initial Features

* User accounts
* Audio file upload
* Select an instrument/stem
* Process audio in the background
* Download the isolated stem
* Download a backing track with that stem removed
* Generate a 75% speed practice version if technically viable
* View processing status and previous jobs

## Technical Goals

Use this project to practice:

* Backend API development
* Databases
* Background job processing
* ML model integration
* Authentication and file access control
* Testing
* Docker and deployment
* Reliability and performance measurement

## Non-Goals

For the first version:

* No custom ML model training
* No YouTube downloading
* No real-time audio processing
* No complex audio editor


## First Release

The first release is complete when a user can upload a song, process it asynchronously, and securely download useful practice tracks through a working web application.


## Future Possibilities

After the initial version is complete, IsoJam may be extended with additional features that make music practice more convenient or effective.

Possible directions may include improved playback controls, practice-oriented audio tools, or other musician-focused features.
